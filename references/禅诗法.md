# 禅诗法（四句，题在画上）

> 这首诗不是"命理诗的翻译"，是**画面的第二层**：画给出矛盾，诗把矛盾说破，但不解释。
> 目标：懂八字的人看得出结构，不懂的人看得出人生。

---

## 一、四句的分工（起承转合，不可换位）

| 句 | 任务 | 写法 | 硬要求 |
|---|---|---|---|
| **起** | 立象 | 一句写主象，**必须有具体物名**（刀、石、舟、树、灯、井） | 不许出现抽象词；不许出现形容词堆叠 |
| **承** | 出矛盾 | 把命局最锋利的那对相反力摆成对仗/对照 | 两句之间必须是**相反的力**，不是并列的景 |
| **转** | 推开 | 一个自然动作（风过、月落、水退、雪压、人走）把矛盾推远一格 | 不许解释、不许抒情、不许出现"人生/命运" |
| **合** | 落所求 | 落到**姿态**：守着什么、去哪里、不做什么 | 不许喊口号；末字宜轻 |

**结构公式**：`物（我）＋物（求/障）相对 → 外力介入 → 我之一念`

---

## 二、格律底线（从宽，但不能破）

- 五言或七言，**四句**，不多不少。
- **一、二、四句押韵**（第三句可不押）；平水韵、普通话韵皆可，但**一韵到底**，不许中途换韵。
- 平仄不强求，但每句须有**一个动词**、**一个实物**。
- 一首诗里**抽象词至多一个**（如"空""静""寒"），其余全是物。

---

## 三、禁用清单（出现即废）

| 类别 | 禁用 |
|---|---|
| 术语 | 官杀、财星、印、比劫、食伤、用神、忌神、空亡、格局、大运、流年、命局 |
| 断语 | 可能、大概、注定、运势、主吉、主凶、宜、忌、克、旺、衰 |
| 励志 | 奋斗、努力、坚持、加油、梦想、未来可期、砥砺、破局、逆袭 |
| 禅味假货 | 一切皆空、随缘、放下、自在、禅心、菩提、明心见性（这些是**结论**，不是象） |
| 抒情 | 啊、叹、奈何、谁人知（除非"谁"是画面的实物关系） |

> 判据：**把诗里每个字换成画面上的东西，能不能指出来。** 指不出来的字，删。

---

## 四、禅意的四个做法（不是加"禅"字）

1. **不解释**：只写发生了什么，不写"这说明"。
2. **以小见大**：不画全山，只写一枝、一刃、一灯。
3. **留一个未答**：第三句可以问，但第四句**不答**，只给一个动作。
4. **以物结情**：末句落在物上（月、霜、灯、舟），不落在情绪上。

## 五、正例

### 例一（庚金坐戌，无根有刃）
```
石上无根铁一枝，
江心倒影万山迟。
风来不问谁磨刃，
只把寒光借月知。
```
- 起：`石`（戌崖）、`铁`（庚）——主象与立足，具体物。
- 承：`江心倒影`＝水旺而空（亥落空），`万山迟`＝满盘是木（财）却在彼岸。
- 转：`风来不问`——外力介入，问而不答，正是缺火（丁藏戌中不透）。
- 合：`借月知`——不求外山（外财），只自照。所求落在"自成为器"。
- 韵：枝、迟、知（支韵），一韵到底。

### 例二（水旺舟停，丙火一点）
```
一江夜水不载舟，
舟上孤灯自点头。
莫问对岸灯几盏，
灯多不照此江流。
```
- 起承：`水`与`舟`分离（有江无路），`孤灯`是丙火独透。
- 转：`莫问`——把"别人的灯火"推开。
- 合：`不照此江流`——所求不是更多光，是此江自有其流。
- 韵：舟、头、流（尤韵）。

## 六、反例（对照改）

| 反例 | 病 | 改法 |
|---|---|---|
| 「命带财星旺，一生求财忙；虽有官杀制，终须靠自己」 | 全是术语与白话，无象 | 换成：`担水入林不见林，一肩湿透两肩轻` |
| 「人生如梦，一切皆空，放下执念，方得自在」 | 禅味假货，四句全抽象 | 换成：`井底有天看不见，一枚月在小儿手` |
| 「他像一把刀，却找不到刀鞘」 | 明喻＋解释，等于把话说尽 | 换成：`刃口向北风向北，鞘在南边未打成` |
| 「山高水长路漫漫，努力终会到彼岸」 | 励志，无矛盾 | 换成：`山头一步到江边，江边一步到山头`（原地打转，才是矛盾） |

## 七、写完自检六问

1. 四句里能不能指出**至少四件实物**？
2. 起句是不是**主象**（日干/日支那件东西）？
3. 承句是不是**真的相反**，而不是并列？
4. 有没有一个术语、一个断语、一个励志词？（有就删）
5. 抽象词是否 ≤1 个？
6. 一、二、四句是否同韵？

六问全过，才允许叠到画上。

## 八、款识与印（题诗的附属）

- **款**（一行小字）：`画题四字 · 干支纪年＋时令`，例：`铁未成器 · 丙午孟冬`。
- **绝不写四柱、不写日主干支、不写任何命理字样**——款是画的题名，不是命书的注脚。用户要看的是画，不是排盘。
- 画题四字从**画眼**里取（刃上的霜→「铁未成器」；江上的雾→「雾锁孤舟」），要像斋名，不像断语。
- 时令写实际的创作时令即可（`丙午孟冬`、`乙巳霜降`），不必与命局月令对应。
- 不加姓名、不加"敬题""雅正"这类客套。
- **印**：一个字，取画眼，如「象」「锋」「空」「渡」。朱文小方印，一枚，不叠印，落在款末。
- 若用户点名要"像古画"，可加第二枚白文印于左下，位置低、字小；除此之外不加任何戳记。

## 九、横排与竖排的分别

| | 横排（默认，压在画面下方） | 竖排（沿画面一侧） |
|---|---|---|
| 标点 | **加标点**：前三句句末「，」，末句「。」 | 不加标点，靠空白断句 |
| 断句 | 一句一行，四行等宽居中 | 一句一列，自右向左 |
| 落的款 | 在末行右下，小字一行，款后接印 | 在诗末左侧一列，向下竖写 |
| 适合的构图 | 下方有水、雾、沙洲、平地（横向开阔） | 侧边有整条天空或纸白 |

> 横排更"像题画"，也更好读；除非构图只有侧面一条留白，否则优先横排。
> 横排时字号由「单行最宽处」和「四行总高」共同决定，脚本会自动求，不要手填。
