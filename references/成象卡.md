# 成象卡（八格表 + 提示词骨架）

> 填不满八格不许出图。八格是本技能唯一的质量闸门。

---

## 一、八格表（先填表，再拼提示词）

```markdown
# 成象卡 · 庚金坐戌（男）

| 格 | 内容 | 取象依据 |
|---|---|---|
| 主象 | 一柄未开刃的长刀 | 日干庚＝顽铁；戌中丁火未透，故"未成器" |
| 立足 | 一方孤立高崖，崖身有炉膛裂口 | 日支戌＝炉、高崖、窑冶 |
| 求 | 隔江一片挺直的疏林 | 甲乙木为财，满盘皆木而在彼岸；甲庚冲→树与刀相向 |
| 障 | 江面薄雾＋水中倒影（倒影比实物淡） | 亥水落空、子未穿；空亡用虚写 |
| 色 | 墨立骨，石青石绿淡染远山与林，赭石染崖，朱砂只点余烬，藤黄染月 | 金重水多→墨为主、青绿为辅；戌为火库→一点朱砂 |
| 天气 | 将暮未暮，一丸淡黄冷月 | 无丙丁明火，唯月（辛）可用 |
| 空间 | 远山极淡（年）／疏林在中右（月）／崖与刀在左中（日）／下部三分之一江面起雾（时＋题字带） | 年月日时四宫 |
| 画眼 | 刃口上的一层薄霜 | 庚无根（申酉不见）、亥月寒气；霜即是"未成器"的可见证据 |
```

**核心矛盾（白话三句，60–100 字）**：见 `白话解析.md`，不进 prompt。

> 矛盾句只进象稿与回复。进 prompt 会把画面说死。

## 二、提示词骨架（按段落填，保持顺序）

```
【画种】宋人青绿淡彩山水，绢本设色，竖幅，工写结合：山石树木以墨线立骨，颜色薄薄罩染其上。
【主体】{主象}，位于{画面位置}，{状态/材质/细节}。
【立足】{立足之景}，{质感}，{与主体的关系：压/托/围/穿}。
【所向】{求}，在{远/中景}，{为何可望不可即}。
【之障】{障}，{如何阻断}。
【题字带】画面下部约三分之一是{水面/平沙/雾}，{一层薄薄的白雾使这一段色调转淡转浅}，横向开阔疏朗、不设近景杂物与礁石，留作题字处。
【光】全画单一柔和的冷光，天光均匀洒下，不要明显的光束、不要光柱、不要丁达尔效应，{天将暮未暮}。
【色】以墨为骨，石青、石绿、赭石、朱砂、藤黄为辅，淡彩薄染、见笔见绢，{冷/温}中带{润/苍}；{某处}略点朱砂。
【气】气韵{清冷/温厚/孤峭/苍茫}，克制、静、有锋藏于内。
【禁】无人物，无文字、无书法、无印章、无落款，无现代器物，无边框、无装裱，无水印。
```

### 负向词（固定附在末尾）

```
不要写实照片感，不要3D渲染，不要卡通/插画感，不要高饱和霓虹色，不要浓艳大红大绿，
不要金碧辉煌，不要人物，不要任何文字或书法或印章，不要边框与装裱与logo水印，
不要满构图，不要多光源，不要光束、不要光柱。
```

## 三、参数

| 项 | 值 | 说明 |
|---|---|---|
| size | `1024x1536` | 竖幅；横披/小品用 `1536x1024` |
| quality | `high` | 设色的层次吃质量，勿用 low |
| style | 留空 | 风格已写进 prompt，避免风格词打架 |
| 出图张数 | 先 1 张 | 不满意改 prompt 再出，不做四宫格盲抽 |

## 四、迭代规则（用户说"不对"时改哪一段）

| 用户反馈 | 只改这一段 |
|---|---|
| 太满、太挤 | 【题字带】：提到四成，并写明"仅三件物" |
| 太素、看不出结构 | 【主体】：加材质与刃口/裂口/纹理的具体描述 |
| 太像风景照 | 【主体】：把主体收成**单件器物**（刀、灯、舟、井），不许是"一片" |
| 颜色太艳、像年画 | 【色】：改"淡彩薄染、见笔见绢"，负向词加"不要浓艳""不要高饱和" |
| 颜色太灰、像水墨 | 【色】：点名"石青石绿要有肉眼可辨的青绿"，并把【画种】改成"青绿山水" |
| 题字处太暗、字看不清 | 【题字带】：加"一层白雾使这一段色调转淡转浅"；脚本侧加 `--veil` |
| 顶上有道光束 | 【光】加强对句"不要光束、不要光柱、不要丁达尔效应"，并写进负向词 |
| 想换风格 | 只改【画种】一行的风格名（见 SKILL.md 风格档），其余不动 |

## 五、出图之后的核对（三步）

1. **数物**：画面上的物能不能一一指到八格？多出来的、指不回去的，重出。
2. **读矛盾**：把画给一个不懂八字的人看，问他"这画里什么和什么在较劲"——答得对，成；答"挺好看"，重出。
3. **题字处够不够**：下三分之一是否横向开阔、色调偏淡？太暗就加雾重出（比硬压一层白雾好看），或用 `--veil 70~90`。
