# 示例 · 庚金坐戌（男）

> 用途：本包示例。演示「结构 → 象 → 画 → 诗 → 白话」五步如何一一对应。
> **对外交付不出现四柱**；第一节的干支只给写技能的人看，用来核对取象。

## 一、结构与取象（内部核对用）

| 位置 | 干支 | 画面上要用的信息 |
|---|---|---|
| 年 | 甲子 | 甲＝高树、栋梁；子＝水。甲庚遥冲 → 树与刀隔江相向 |
| 月 | 乙亥 | 乙＝柔木、疏枝；亥＝江。**亥落空** → 江是虚的，用倒影写 |
| 日 | 庚戌 | 庚＝顽铁、刀斧，无火不器；戌＝炉、高崖、窑；戌中丁火未透 → 一点余烬 |
| 时 | 癸未 | 癸＝雨露；未＝田园台地。时柱主出路 → 画成无桥无舟 |

- 满盘甲乙木（财）而在年月（彼岸），日主庚在近景 → **求在远，我在近**。
- 申酉不见（禄刃不全）→ **刀无根、无柄**。
- 戌亥双空 → 立足处是空的，水是虚的。
- 矛盾一句：**手中有利刃，刃下无石；万木在对岸，舟不来。**

## 二、八格

| 格 | 内容 | 取象依据 |
|---|---|---|
| 主象 | 一柄未开刃的长刀横陈崖顶，刃口钝重覆薄霜，刀柄残破无缠绳 | 日干庚＝顽铁；无明火炼 → 未成器；禄刃不见 → 无柄 |
| 立足 | 孤立高崖，崖身一道炉膛状裂口，深处一点将熄的暗红余烬 | 日支戌＝炉、窑、高崖；丁火未透 → 余烬 |
| 求 | 对岸一片疏林，枝干挺直如戟，林后远山石青石绿淡染 | 甲乙木为财，全在年月彼岸；甲庚冲 → 树与刀相向 |
| 障 | 江面薄雾；水中倒影比实物更淡；无桥无舟 | 亥水落空；时柱无出路 |
| 色 | 墨立骨；赭石染崖、石绿花青点叶、石青染远山，朱砂只点余烬，藤黄染月 | 金重水多 → 墨为主、青绿为辅；戌为火库 → 一点朱砂 |
| 天气 | 天将暮未暮，一丸淡黄冷月；天光均匀，无光束 | 无丙丁明火，唯月可用；亥月主寒 |
| 空间 | 远山极淡（年）／疏林在中右（月）／崖与刀在左中（日）／下部三分之一江面起雾（时＋题字带） | 年远、月中、日近、时出路 |
| 画眼 | 刃口一层薄霜 | 庚无根＋亥月寒气；霜是「未成器」唯一可见的证据 |

## 三、白话解析（对外就这么说）

**核心矛盾**

> 你手上其实有一件真东西——一把能用的刀，只是还没开刃。你真正想要的是对岸那一片林子：做成一件事、被认下来、把本事换成实实在在的东西。可卡住你的是：刀在崖上，林在江对岸，中间没有桥也没有船——你有本事、有目标，缺的是把两者连起来的那条路，而这条只能自己一段一段铺。

**破局三条**

一、先别急着过江。把崖上这块地盘做深：已有的客户、已有的手艺，再往下挖一层，比追新岸口省力。
二、缺的不是火，是"磨"的动作。找一个能挑你毛病的人（同行、客户、比你狠的前辈），定期把作品交出去挨批——这就是你的磨石。
三、这周挑一件拖了很久的小事，做到能拿出手为止；做完把它发出去，不等完美。

> 三条各管一件：一管方向（别追远），二管方法（借外力打磨），三管动作（今晚能做）。

## 四、诗（横排，四行）

```
石上无根铁一枝，
江心倒影万山迟。
风来不问谁磨刃，
只把寒光借月知。
```

- 起：`石`＝崖，`铁`＝刀。主象与立足，落到具体物。
- 承：`江心倒影`＝水旺而空，`万山迟`＝满盘是木却在彼岸。虚实相反，是真矛盾。
- 转：`风来不问`——外力来了，却不回答「谁磨刃」，正因为缺火。
- 合：`借月知`——不求对岸之林，只自照。所求在「自成其器」，不在外财。
- 韵：枝、迟、知（支韵），一韵到底。
- 款：`铁未成器 · 丙午孟冬`；印：`象`。

## 五、提示词要点（完整版见同目录 `提示词.txt`）

1. 画种先定死：宋人青绿淡彩、绢本设色、竖幅、近景工写＋远景没骨淡染。
2. 主体必须是**单件器物**（一柄刀），不能是「一片山」。
3. **下三分之一**要写成「江面＋一层薄白雾，雾使这一段色调转淡转浅、横向开阔无杂物」——题字带靠雾解决，别靠拼一条空白。
4. 光写"天光均匀"，并明确"不要光束、不要光柱、不要丁达尔"。
5. 色写"淡彩薄染、见笔见绢"，朱砂只点一处（余烬），别处不许见红。
6. 负向词必须写：无人物、无文字、无印章、无边框、不要满构图、不要多光源。

## 六、这一版踩到/修掉的三个坑

| 坑 | 现象 | 处理 |
|---|---|---|
| 「单一光源自左上斜下」被画成一道光柱 | 顶上一道斜白束，像舞台灯 | 改写成"天光均匀洒下"，并把"光束/光柱/丁达尔"写进负向词 |
| 竖条留白被画成拼接带 | 一侧亮白竖带，边缘硬接缝＋暗边 | v1.1 改用**底部雾带**，竖条版式只作备选 |
| 题字带压纸色压出方形亮斑 | 下缘一块能看出四边的浅色矩形 | `--veil` 改为整幅宽、自上而下渐入，并把左右硬边去掉 |
