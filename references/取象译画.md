# 取象译画（象法 → 画面）

> 底本：`ps-duan-xiangfa`（段派取象）、`ps-tiwei-zuogong/references/干支类象.md`（《段氏理象学》十干/十二支类象）、`ps-duan-mianshou` 象法七原则。
> **本文件只做一件事：把原书里"断事用的物象"改写成"入画用的母题"。** 象的老意思不动，只换成能画出来的说法。

## 一、取象四层（顺序不能乱）

| 层 | 取什么 | 落的格 |
|---|---|---|
| 1 | 日干＋日支 | **主象**与**立足** |
| 2 | 命主要在弄住的东西（财/官/食伤） | **求**（画中远处的目标物） |
| 3 | 坏功神、克我、落空之字 | **障**（画中阻断之物） |
| 4 | 月令＋五行多寡 | **色**与**天气**（决定整幅调子） |

**取象优先级**：日主之象 > 日支之象 > 功神之象 > 忌神之象 > 其余所有字（多半不入画）。

### 合象：日主 ＋ 坐支要拼成一件物（拼不出来说明取窄了）

表是**单字表**，而真实案例里主象几乎从来不是单字，而是「日主之质 ＋ 坐支之形」拼出来的一件东西。两字都查得到，拼法是自己的事：

| 组合 | 拼出来 | 拼法 |
|---|---|---|
| 庚 ＋ 戌 | 一柄横陈崖顶的刀 | 庚＝刃，戌＝崖；刃搁在崖上，崖供其立足 |
| 辛 ＋ 酉 | 一面立在碑顶的铜镜 | 辛＝小件精器与冷光，酉＝金石碑碣；精器立石上、面朝外即成镜 |
| 丙 ＋ 午 | 一盏高悬的灯 | 丙＝光，午＝高处；光悬在高处 |
| 癸 ＋ 丑 | 一只冻着的陶罐 | 癸＝水、霜，丑＝湿土、窖；水盛在土器里 |

三条拼法：

1. **一物一功能。** 镜只用来照，不要又照人又盛水；拼出两用，画面就散了。
2. **柔取"用"，刚取"形"。** 辛、癸这类柔字给"能做什么"，酉、戌这类硬字给"长什么样"。
3. **拼不出来就退回单字，别三合一。** 宁可画一柄刀，不要画"刀＋崖＋炉"三合一。

> 这一条是实跑出来的：某局「辛坐酉」，单字表里只有"针／剑／珠玉"与"碑／金石"，硬查只能画成一把剑立在碑上，出不了"照见"这个动作；拼成铜镜，整幅画的核心矛盾才立得住。

## 五、作用关系 → 构图语法（本技能最要紧的一张表）

| 结构 | 画法 | 力度 |
|---|---|---|
| **制**（克住） | 一物压住/笼住另一物：石压竹、笼中鸟、刀斫木 | 最实，画面的"功"就在这一笔 |
| **合**（六合/五合） | 两物相连：藤绕石、桥接岸、绳系舟、根抱岩 | 牵引、缠、留 |
| **穿**（害） | 锐物入体：钉入木、箭穿云、竹穿石，入而不透 | 暗损，画裂不画断 |
| **冲** | 对撞/对峙：双峰夹江、浪击崖、两树相向 | 明动，宜左右分立 |
| **刑** | 磨损：石面刻痕、器物缺口、老树疤 | 不显于形，用质感表现 |
| **墓** | 收进容器：深潭、洞窟、闭匣、井 | 收藏与控制 |
| **库**（开） | 启开的仓、半掩的门、露出的器 | 能得 |
| **空亡** | **虚写**：倒影、淡影、镜中之物、云中缺口、半透明的远山 | 整幅画的"虚"全靠这一笔 |
| **伏吟/共象** | 同物再现：水中有影、画中画、回文式对称 | 重复、加重 |

> **一条硬规矩**：一幅画里 **作用关系最多画三种**（一主一辅一虚）。四种以上必乱，观者读不出矛盾。

## 六、宫位 → 空间层次

| 柱 | 空间 | 画什么 |
|---|---|---|
| 年 | 远景／天 | 远山、故土、来处、日月、飞鸟 |
| 月 | 中景／场 | 门阙、市、林、事业场、社会 |
| 日 | 近景主体 | 我、我的立足处、枕席、门内 |
| 时 | 前景／出路 | 路、舟、桥、门、幼者、归处 |

> 年月空亡 → 远景虚写；日支空亡 → **脚下是空的**（最狠的一笔，用悬石、水影、残阶）；时柱空 → 出路未见，画一条断头路。

## 七、五行 → 色与天气（设色版）

主色**永远只有五个**：墨、石青、石绿、赭石、朱砂，外加绢底的米黄与一点藤黄。多一色即俗。

| 五行 | 设色 | 墨/笔 | 材质 | 天气 |
|---|---|---|---|---|
| 木旺 | 石绿、花青（点叶）、汁绿（染坡） | 淡墨勾干，笔要挺 | 枝、叶、纸、布 | 风、春岚 |
| 火旺 | 朱砂、朱磦（只点一处）、藤黄（灯晕） | 焦墨立骨 | 陶、铁、灯 | 晴、晚霞、暑气 |
| 土厚 | 赭石、土黄（染崖、坡脚） | 干笔皴擦，见飞白 | 石、墙、陶 | 尘、雾、沉 |
| 金重 | 石青＋冷灰（山阴）、留白代刃光 | 干墨、飞白、硬折笔 | 刃、石、骨 | 霜、秋气、薄寒 |
| 水多 | 淡花青（水）、蛤白（雾） | 淡墨横扫，不勾水纹 | 江、潭、雨 | 雨、雾、夜 |

**用色三条纪律**（淡彩最容易翻车的地方）：

1. **墨是骨，色是皮。** 色永远薄薄罩在墨线上，不许盖住笔线，不许平涂色块。
2. **一亮一暗，其余都淡。** 全画只允许一处最艳（通常是朱砂那一点），一处最亮（雾或月），其余全在中低对比里。
3. **青绿只上远山与树，不上一切。** 青绿一满，就成了年画。

水墨版（`ps` 用户点名要"素"时）仍按旧法：焦墨、淡墨、赭石、朱砂一点、纸白，只五色。

## 八、神煞 → 点缀（佐证层，最多两处）

| 煞 | 点缀 |
|---|---|
| 天乙贵人 | 一枚不起眼的旧物、一盏为他留的灯 |
| 华盖 | 孤树、伞盖、独亭 |
| 驿马 | 一叶舟、一道车辙、一匹马影 |
| 桃花 | 落花三两片（不可满树） |
| 羊刃 | 刃上缺口、缠刃的布 |
| 空亡 | 见前表，虚写 |
| 墓库 | 见前表，容器 |

> 神煞只作**点缀**，不进主体。画面上神煞超过两处，就是拿神煞断命，本技能不做。

## 九、消歧：一字多象怎么定

原书明说"一干多象是常态"，画面上必须锁死一个：

1. **所临十神优先**：申作刀还是作车？临七杀取刀，临财取车。
2. **宫位次之**：同一字在年取远景（旧物、故地），在日取贴身（手中器）。
3. **旺衰最后**：旺者取其大（江海），弱者取其小（露、滴）。
4. 仍锁不死 → 取**最能入画**的那一个，并在象稿「取象依据」里写明"三选一，取某"。
